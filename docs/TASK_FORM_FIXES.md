# Исправление создания задач — 3 октября 2026

## Исполнитель

Форма читала `data.users`, хотя `/api/users/department?role=user_analyst`
возвращает массив напрямую в `data`. Теперь используется фактический контракт API.
Список загружается для активного отделения, при переключении прежний выбор
сбрасывается, запрос предыдущего отделения отменяется. Отдельно показываются
загрузка, ошибка API и отсутствие аналитиков. Создание блокируется до получения
доступных исполнителей; backend сохраняет проверку доступа к отделению.

## Приоритет и номер

Приоритет выбирается четырьмя подписанными кнопками на основе native radio:
низкий, средний, высокий, срочный. Средний выбран по умолчанию. Выбор отмечается
цветом и галочкой, поддерживаются клавиатура и видимая рамка фокуса. На узком
экране кнопки располагаются в два ряда.

Для «Генетические экспертизы» форма, список и карточка задачи используют
«Номер экспертизы»; для ЧС — «Номер привоза». Подпись диапазона также зависит
от отделения. Назначение и завершение задачи создают уведомления с правильным
названием номера по отделению самой задачи.

Поля API/БД `internal_number_start` и `internal_number_end` сохранены:
это справочный номер задачи. Миграция БД для этих исправлений не нужна.
