# Рефакторинг: Фаза 3 — границы frontend/backend и сервисы

Дата проверки: 13 октября 2026 г. План Фазы 3 подтверждён пользователем.

## Структура

Все 12 React/браузерных файлов из `src/components/bayesian/` перенесены в
`frontend/src/components/Analysis/Bayesian/`. `BayesianShell` подключает
компонент из frontend; ссылка `SampleSelector` на hook исправлена.
Webpack уже использует entry `frontend/src/index.js` и корректный HTML-шаблон,
поэтому дополнительных изменений его конфигурации не требуется.
Проверка CSS теперь сканирует только frontend.

Клиентские модули называются `dnaAnalysisApi`, `exportApi`, `taskApi`,
`organizationApi`, `duplicateExportApi`. Импорты, динамический импорт экспорта
и имена экспортируемых объектов обновлены. Общий `httpClient` заменяет ссылки
на отсутствовавший `authService` и использует существующие `token`/`user` из
localStorage. Активное отделение читается перед каждым запросом. Поддерживаются
JSON, FormData без ручного multipart boundary, Blob, AbortSignal, ответы 204
и прежний контракт ошибок `{ response: { status, data } }`. Внешние URL
не принимаются, чтобы токен не отправлялся стороннему серверу.

Это транспорт, а не миграция всех экранов на новый клиент: текущие работающие
экраны продолжают использовать свои fetch-вызовы и AuthContext.
Сохранённые исторические API-обёртки не подключены заново к роутеру.

42 backend-сервиса распределены по папкам:

| Папка | Назначение | Число файлов |
| --- | --- | ---: |
| `infrastructure` | БД, Redis, очереди, health, WebSocket, настройки | 10 |
| `security` | Авторизация, доступ, загрузка, пользователи, шифрование | 7 |
| `converters` | Excel, NGS, определение формата и проверка файлов | 6 |
| `contamination` | Сравнение с сотрудниками и журналирование | 3 |
| `profiles` | Анализ, массивы, аллельные справочники, поиск, снимки результатов | 8 |
| `tasks` | Задачи, восстановление привязок и уведомления | 4 |
| `audit` | Журналы и экспорт | 4 |

`src/services/bayesian/` сохраняет математическое ядро. Обновлены входящие
и внутренние импорты, ссылки в server, middleware, моделях, routes, workers,
тестах и скрипте восстановления профилей. Исправлены пути к SQL-схеме,
миграциям и worker относительно нового `__dirname`.

## Удалённые неподключённые фрагменты

До изменения они не были достижимы из `frontend/src/index.js` и не входили
в production bundle. Проверены ссылки по всем исходникам:

- `Analysis/BayesianAnalysisPanel`: отсутствовавшие feature/bayesian/export
  зависимости; действующий `/bayesian` использует перенесённый BayesianAnalysisApp.
- `Analysis/SearchInterface`: отсутствовавшие настройки и hook;
  действующий `/analysis` использует GenotypeAnalysisPage.
- `Common/NotificationCenter`: отсутствовавший сервис;
  уведомления приложения работают через useNotifications/WebSocket/ToastWrapper.
- Четыре `Population/*` компонента: отсутствовавший bayesianService,
  нет маршрута и внешнего использования. Неподключённый редактор популяций
  не заменён новым экраном. Серверный PopulationManager, частоты и справочники
  сохранены; работающие экраны справочников не изменены.

Устранены все 15 отсутствовавших относительных импортов. Заглушки API не добавлялись.

## Проверки

После каждого из трёх шагов выполнялись `npm test`, `npm run check:ui`
и production webpack build. После окончательного переноса:

- обычный прогон: 192 теста, 181 pass, 5 skip, 6 TODO, 0 fail;
- расширенный прогон на пяти отдельных свежих PostgreSQL БД:
  247 тестов, 239 pass, 1 skip, 7 TODO, 0 fail;
- три новых теста транспорта проверяют актуальность отделения/токена,
  локальность URL, multipart, Blob, отмену и ошибки;
- `npm run check:imports`: 253 JS-файла, 795 относительных импортов,
  неразрешённых ссылок нет. Проверка включена в Dockerfile;
- синтаксические деревья всех 42 серверных и 12 браузерных модулей совпали
  с исходными после нормализации путей. Парсинг аллелей и расчёты не менялись;
- UI: 40 stylesheets, 2674 selectors, 72 animations;
- webpack: две прежние рекомендации о размере bundle, ошибок нет.

Production-образ на Node 20 собран из файлов репозитория и запущен с отдельными
PostgreSQL/Redis и временным ключом. Проверены login, HTTP frontend, полное
состояние health (`healthy`), массовый поиск на 104 синтетических профилях
и контрольный профиль другого отделения. Результаты single-threaded и
multi-threaded совпали, snapshot содержит 5356 пар. Экспорт через настоящий API
вернул XLSX с листами «Профили» и «Сравнения»; заголовки сравнений сохранены.
Попытка экспорта того же snapshot из другого отделения вернула 403.
Playwright открыл `/bayesian`, переключил вкладки и загрузил выбор образцов:
ошибок страницы и сообщений console.error нет.

Один skip относится к необязательному частному NGS-образцу. TODO MATH-01–06
и DB-01 описаны в предыдущих отчётах. Они не считаются успешными тестами.
