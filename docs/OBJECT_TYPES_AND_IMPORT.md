# Типы объектов и импорт

Новый процесс включается при согласованном переходе по
[инструкции выпуска](LEGACY_EXPORT_AND_REIMPORT.md). До включения работает прежний интерфейс.

Единый справочник браузера и сервера — `src/utils/objectTypes.js`:
`chs` — ЧС, `ug` — УГ, `gr` — ГР, `staff` — Сотрудник.
Тип не определяет роль пользователя, отделение или формат исходного файла.
Нераспределённая историческая запись сохраняет пустую категорию; новые включённые
строки требуют заполненного типа, года 1900–2100 и полного номера объекта.

У сотрудника номер объекта совпадает с регистрационным номером: `00870-G`.
Нужны ФИО и год; ведущие нули сохраняются. Различные значения «Объект» и «№ рег.»
требуют исправления. Имя человека не является ключом. У обычных объектов ФИО не
обязательно и не используется; свободный текст хранится отдельно в `comment`.
Старые `notes`, привоз, номера, UUID и метаданные сохраняются в происхождении.

Excel/XLS, GeneMapper TXT и NGS ASTR+ проходят общий draft → validate → commit.
Используются действующие normalizer, GeneMapper/NGS parsers и QC.
Отсутствующие год/категория не мешают открыть файл. Общий год не подставляется
из часов или имени файла: предложение из имени хранится отдельно от принятого значения.

В таблице загрузки:

- чекбокс включает строку в импорт; служебные образцы исключены и не становятся сотрудниками;
- выбор всех действует на весь текущий фильтр, включая другие страницы;
- год и тип применяются явно к выбранным, всем или незаполненным строкам;
- перезапись заполненных значений подтверждается; последнюю массовую правку можно отменить;
- индивидуальные правки сохраняются в черновике автоматически; CAS-ревизия защищает от двух вкладок;
- аллели и источник открываются отдельно; ручное решение сохраняет исходные значения;
- ошибочная снятая строка остаётся в диагностике, но не блокирует остальные;
- после успешной проверки автоматически скачивается актуальный нормализованный XLSX;
- в личный массив записываются только отмеченные строки, атомарно, с idempotency key.

Два исходных номера не объединяются до назначения годов/типов. Рабочая уникальность:
`workspace + тип + год + lower(trim(полный номер))`. Общая уникальность публикации:
`организация + тип + год + полный номер`; автор и прежнее отделение ключ не расширяют.

Пустой именованный профиль сохраняется без фиктивных аллелей. Полностью пустая строка
игнорируется. Неверные аллели и неразрешённый QC не превращаются в пустой профиль.
Структурные ошибки нельзя убрать одним изменением типа. При необходимости сложного
сопоставления шапки/локусов используйте существующий конвертер перед загрузкой.

Лимиты: 100 файлов, 10 МиБ на файл, 50 МиБ суммарно (контролируется в потоке),
2 миллиона ячеек на исходный табличный лист. Превышение отклоняет файл целиком,
не отрезает хвост. Большие миграционные выгрузки автоматически делятся на части.
