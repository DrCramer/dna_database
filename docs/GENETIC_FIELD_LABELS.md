# Подписи идентификаторов для генетических экспертиз

Изменены только пользовательские подписи двух существующих полей:

| Существующее поле | Подпись в «Генетических экспертизах» |
|---|---|
| `sample_name` / `sampleName` | № Экспертизы |
| `internal_number` / `internalNumber` | № Объекта |

## Реализация

Общий помощник находится в `frontend/src/hooks/useProfileFieldLabel.js`.
Он получает `activeDepartment` из `AuthContext` и использует существующий
`resolveProfileImportFormat`. Компонент передаёт своё прежнее название поля:
для ЧС и любого другого отделения оно возвращается без изменения.

Изменены следующие React-компоненты:

- `GenotypeAnalysisPage`: данные, результаты, история, эталон, детали
  контаминации и окно деактивации.
- `ProfileCommentModal`: подпись идентификатора в окне комментария.
- `MasterObjectSearchPage`: карточка, результаты, подсказка поиска и текст
  ошибки пустого запроса.
- `AdminDashboard`: подписи в таблицах и панели поиска дубликатов.
- `ProfileViewer`: заголовок таблицы, поиск и подпись варианта сортировки.
- `ProfileViewer` в `App-fixed.js`: заголовок и подсказка поиска.
- `ResultsDisplay`: таблица и просмотр совпадения.
- `SearchInterface`: подпись варианта сортировки.
- `StaffContaminationPanel`: сведения о выбранном профиле и результате.
- `SampleSelector` в `src/components/bayesian`: подпись номера и placeholder.
  Это React-компонент интерфейса; серверная часть не изменялась.

Отдельные экраны партий, создания/сохранения протоколов в этой версии проекта
отсутствуют. Дополнительные экраны не создавались. Подписи номера задачи,
привоза, года, ID, номера строки и технического имени профиля не изменялись.
Старые заголовки Excel в справке загрузки остаются в ветке ЧС; текущий формат
импорта genetic с колонкой «Объект» сохранён.

## Сохранность данных и проверка

Существующие значения читаются из прежних свойств. Значение `256` остаётся
`256`, а `256-1`, `256-2`, `256-3` отображаются целиком. Новые числовые свойства,
разбор номера на части и изменение формата не добавлены. Схема БД, миграции,
API, импорт, экспорт, фильтры, сортировка и алгоритмы не изменялись.

Проверка AST десяти изменённых React-файлов подтвердила сохранение логики после
исключения UI-разметки и помощника подписей. В браузере проверены обе пары
подписей, сохранение значений на тестовых данных, переключение отделений
без повторного входа, обновление страницы, форма эталона и карточка поиска.
`npm run check:ui` и `npm run build` завершились успешно.

На установленном контейнере проверены также панель дубликатов администратора
и выбор образца в байесовском анализе. Терминология корректна, когда выбранное
отделение отличается от основного отделения пользователя. Значения строк
анализа совпадают с ответом API. Контрольная сумма идентификаторов и привязок
всех 6078 профилей до и после обновления совпала.
