# Импортируемый XLSX DNA_IMPORT_V2

Первый и единственный лист — «Импорт», строка 1 — шапка.
Используется общий `createImportWorkbook()`, свойство книги
`DNAProfileSourceFormat=DNA_IMPORT_V2`. Это маркер формата, не доверенный статус.

```text
Объект | Год | Тип экспертизы | ФИО | Комментарий | № рег.
Старое отделение | Источник записи | Исходный ID | Прежнее имя образца
Старое значение привоза/служебной колонки | Исходный номер из файла
Происхождение JSON | Генотип JSON | локусы…
```

ФИО/№ рег. используются для staff. В обычной записи ФИО пустое. Прежние значения
не перезаписываются категорией: подробности, notes/metadata, дополнительные номера,
исторические UUID и источник находятся в provenance. Отдельного диагностического
листа нет. Половые локусы расположены после остальных.

Видимые локусы и «Генотип JSON» сохраняют количество, порядок и специальные значения
аллелей. V2 не применяет экспортное сокращение повторов DYS391/DXS/RS и не добавляет
вторую аллель к одиночной. Это специально описанный формат переноса, а не подмена
типа файла на GeneMapper. Несогласованность JSON и видимой ячейки требует явного
ручного решения. Структурно повреждённые значения не превращаются в пустые.

Содержимое, похожее на формулы, записывается строковым типом `s` с форматом `@`.
Апостроф не добавляется к бизнес-значению. Строки длиннее предела ячейки Excel
отклоняют выгрузку с ошибкой без усечения; исходная БД остаётся неизменной.

Импорт файла создаёт новый черновик и новые рабочие UUID. Исходный ID не позволяет
назначать owner, организацию, статус публикации, готовность поиска или перезаписывать
чужую запись. Подпись старого отделения не превращает запись в УГ.

Черновик зашифрован, принадлежит организации/пользователю, связан с checksum каждого
источника и ревизией. TTL — 24 часа; истёкшие незаписанные черновики удаляются
почасовой уборкой. Записанные рабочие профили TTL не имеют. Идемпотентный ключ
сохраняется клиентом для повторной попытки при сетевом сбое.

```http
POST  /api/workspace/import-drafts                 multipart files (до 100)
GET   /api/workspace/import-drafts/:id
PATCH /api/workspace/import-drafts/:id/rows        {revision,rows:[{draftRowId,...}]}
POST  /api/workspace/import-drafts/:id/validate    {revision}
POST  /api/workspace/import-drafts/:id/export      {revision}
POST  /api/workspace/import-drafts/:id/commit      {revision,idempotencyKey}
```

При изменениях preview/готовый файл заменяются новой ревизией. Снятые строки не
пишутся. Ошибка одной включённой записи откатывает весь commit. Чтобы импортировать
исправную часть, явно исключите проблемные строки. Неактивные/служебные образцы и
конфликты остаются видны в таблице.

Выгрузка GeneMapper именуется исходным TXT с расширением `.xlsx`. Выгрузка БД —
`Генотипы_годы_дата.xlsx`. При разбиении скачивается ZIP с самостоятельными XLSX
и реестром количества/фильтров; части загружаются вместе в новую таблицу.
